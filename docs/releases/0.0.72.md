# Bubble 0.0.72

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changed

- A Nex-N2.6 request on MOSS now says that the model thinks: it carries
  `thinking.type: "enabled"`, the one value the MOSS docs give for the field.
  0.0.71 left the field out. The model thought either way, so replies do not
  change.
- Nex-N2.6 still has no reasoning-effort setting. The MOSS docs name none, and
  the `reasoning_effort` values the endpoint accepts made no difference to how
  much the model thought when measured, so Bubble sends none.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

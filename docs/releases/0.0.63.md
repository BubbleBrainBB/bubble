# Bubble 0.0.63

This release replaces the TypeScript CLI in the `@bubblebrain-ai/bubble` npm
package with the native (Rust) Bubble. It does not publish a desktop
application update.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

npm installs the build for your machine from one of the platform packages
(`@bubblebrain-ai/bubble-darwin-arm64`, `-darwin-x64`, `-linux-x64`,
`-linux-arm64`, `-win32-x64`). Node is only needed to install it.

## What stays the same

- The same `bubble` command, flags and output: `-p`, `-m`, `--cwd`, `-r`,
  `--session`, `--reasoning-effort`, `--plan`,
  `--dangerously-skip-permissions`, `--output-format plain|json|stream-json`
  and `--input-format stream-json`.
- The same files: `~/.bubble/config.json`, `auth.json` (ChatGPT and Grok
  sign-ins), `settings.json` (MCP servers and hooks), skills, agent profiles
  and memory.
- Your earlier sessions: the first start brings in the sessions in
  `~/.bubble/sessions` once (`bubble import-sessions` does it by hand), so
  `/session` and `-r` continue them. The files themselves are not changed.

## Changes

- A new full-screen terminal UI, with input history, `@file` mentions,
  image paste (Ctrl+V), diff previews for edits, a light theme (`/theme`),
  and `/model`, `/effort`, `/session`, `/compact`, `/context`, `/mcp`,
  `/skills`, `/login` and `/logout`.
- Subagents can write: the `implementer` profile edits in its own git
  worktree, which you review and apply.
- Subagent categories (`quick`, `explore`, `deep`, `review`, …) route a child
  to a faster model of your provider when one is known.
- MCP prompts run as slash commands, and HTTP MCP servers that require OAuth
  can be signed in to (`/mcp login <name>`).
- Google Gemini through its native API (protocol `ai-sdk`), and images in
  messages for every provider.
- Anthropic requests use prompt caching, and thinking is sent back correctly
  across tool calls.
- `bubble update` installs the latest version with the package manager you
  used.

## Not in this release

- The Agent SDK that the TypeScript package exported (`import … from
  "@bubblebrain-ai/bubble"`) is not part of the native package. Projects that
  embed it should stay on 0.0.62.
- The Feishu bot (`bubble serve --feishu`) is not in the native CLI yet;
  0.0.62 still has it.

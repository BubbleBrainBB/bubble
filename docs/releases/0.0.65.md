# Bubble 0.0.65

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changes

- Add Gemini 4 Hydrogen (`gemini-4-hydrogen`) to the Google Gemini provider, as
  a balanced-tier model with a 1,048,576-token window shared by input, thinking
  and output. Thinking levels are low, medium, high (default) and xhigh.
- Add Gemini 4 Carbon (`gemini-4-carbon`), Google's most capable reasoning
  model, as a strong-tier model with the same window. Thinking levels are low,
  medium (default) and high, the same as Gemini 4 Argon. Argon stays first in
  the list, so the provider's default model does not change.
- Live Gemini model discovery now recognizes the `carbon` and `hydrogen` tiers.
  Before, both were filtered out, so neither appeared when an API key was
  configured. The five listed models are now Argon, Carbon, Hydrogen and the two
  newest Flash releases.
- Gemini 4 Hydrogen requests at xhigh send `thinkingLevel: "xhigh"`. On Argon
  and Carbon, which reject xhigh with HTTP 400, xhigh and max are still sent as
  high. Requests for "off" or "minimal" are sent as "low" on all three.
- Price Gemini 4 Hydrogen at $1.50 input, $7.50 output and $0.075 cached input
  per 1M tokens, for all context lengths.
- Price Gemini 4 Carbon the same as Argon: $2 input, $10 output and $0.10
  cached input per 1M tokens through 2026-11-30, and $4, $20 and $0.20 from
  2026-12-01.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

# Bubble 0.0.61

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changes

- Add Gemini 4 Argon (`gemini-4-argon`) to the Google Gemini provider. It is
  listed first, as a strong-tier model with a 1,048,576-token window shared by
  input, thinking and output. Thinking levels are low, medium (default) and
  high, matching Google's documented contract.
- Live Gemini model discovery now recognizes Gemini 4's named flagship tier.
  Before, any ID without `pro` or `flash` was filtered out, so Argon never
  appeared when an API key was configured.
- Gemini 4 requests send `thinkingLevel` rather than a 2.5-style
  `thinkingBudget`. Requests for "off" or "minimal" are sent as "low", because
  Gemini 4 has no off switch and rejects `MINIMAL` with HTTP 400. This covers
  side calls such as session titles and compaction, which default to "off".
- Price Gemini 4 Argon at its introductory rate ($2 input, $10 output, $0.10
  cached input per 1M tokens) through 2026-11-30, and at the standard rate ($4,
  $20, $0.20) from 2026-12-01.

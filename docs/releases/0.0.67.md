# Bubble 0.0.67

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Added

- `bubble host --stdio` serves the agent to an app that is not written in
  JavaScript, as line-delimited JSON-RPC 2.0 over stdin and stdout. The app
  starts sessions and turns and reads their events; the host asks the app for
  approvals, answers to questions, plan and folder-trust decisions, and the
  results of tools the app runs itself. Model, skill, MCP server and account
  lists and sign-in go over the same pipe. Every request goes through the SDK,
  so a turn is the turn the terminal runs: same tools, permission rules, hooks
  and session files. `initialize` reports the protocol version (1) and the
  Bubble version. The messages are listed in `src/host/protocol.ts`.
- SDK: a turn may name the folder it works in (`RunTurnOptions.cwd`). Its
  tools, project settings, trust, MCP servers and the prompt's working
  directory follow it, while the session stays in the folder it was made in.
  Before, a session could work in one folder only.
- SDK: an agent may go by a name of its own in the system prompt
  (`agentName`), for an app that runs several long-lived agents.
- SDK: a host may supply its own system prompt, list the built-in tools a turn
  may offer, read MCP server status and reconnect a server, ask for a one-off
  text completion, and shut the SDK down.

## Fixed

- A reply from an OpenAI-compatible provider that was cut off before its
  declared length no longer leaves the turn running forever. The provider now
  streams through Node's own fetch, which fails that read, and a
  chat-completions stream that ends without `[DONE]` or a `finish_reason` is
  treated as an interruption and retried. Print mode (`-p`) used to exit 0 with
  the partial text; it now exits 1 with an error when its turn cannot finish.
- Node's fetch gives up on a response after 300 seconds without a byte, which
  the old transport did not. So that a model thinking in silence is not cut
  off, that wait follows `BUBBLE_PROVIDER_REQUEST_TIMEOUT_MS` and is off when
  the variable is not set.
- Skill frontmatter written as a YAML block scalar (`description: |`) is read
  in full. Before, the description came out as `|`.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

# Bubble 0.0.66

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Fixed

- `/model` now lists Gemini 4 Carbon and Gemini 4 Hydrogen after an upgrade.
  In 0.0.65 the Gemini list could come from the model list an older version
  had saved to `~/.bubble/model-discovery-cache.json`, which is kept for 24
  hours and did not contain the two models. They could still be selected by
  name (`--model google:gemini-4-carbon`), but the picker did not show them.
  The saved Gemini list is now tied to the model tiers a version recognizes,
  so a list saved by an older version, or by an older Bubble still running on
  the same machine, is not reused.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

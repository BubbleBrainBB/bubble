# Bubble 0.0.71

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Added

- MOSS is a built-in provider, with one model, Nex-N2.6 (`nex-n2.6`). Run
  `/provider --add moss`, paste an API key created at `platform.moss.cn`, then
  select `/model moss:nex-n2.6`. Bubble calls OpenAI-compatible Chat
  Completions at `https://api.mosi.cn/v1`, with streaming and agent tools.
- Nex-N2.6 has a 1M context window. It always thinks, so it has no
  reasoning-effort setting, and its thinking is shown as it arrives.
- A reply from Nex-N2.6 may run to 131,072 tokens, the most the endpoint
  allows. Left alone the endpoint stops a reply at 8,192 tokens, thinking
  included, which cuts a long file off part way.
- Usage for Nex-N2.6 turns includes cached input and thinking tokens. MOSS
  lists the model as free for a limited time, so no price is attached and no
  cost is shown.
- `/model` lists Nex-N2.6 only under MOSS. The provider's own model list is
  mostly speech, transcription and image models, which cannot hold a
  conversation. A dated snapshot such as `nex-n2.6-2026-11-05` is not listed
  but can be named in `models.json`, and is sent the same request.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

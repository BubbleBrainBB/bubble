# Bubble 0.0.62

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Changes

- Fix Kimi K3.1 failing with `400 invalid temperature: only 1 is allowed for
  this model`. K3.1 Pro and K3.1 Pro Highspeed (`k3.1-pro`,
  `k3.1-pro-highspeed` on Kimi for Coding; `kimi-k3.1-pro`,
  `kimi-k3.1-pro-highspeed` on Moonshot CN/international) are now in the model
  catalog. They are thinking-only, with low, high (default) and max effort.
- Moonshot models missing from the catalog no longer send a temperature, so a
  newly released Kimi model does not fail the same way.
- Add Kimi on Alibaba DashScope. Requests never send a temperature.
  - `kimi-k3` supports off, low, high (default) and max.
  - `kimi-k2.6` and `kimi-k2.5` have a thinking on/off switch.
  - `kimi-k2.7-code` always thinks.
  - The `kimi/`-prefixed models follow DashScope's documentation: the K3 and
    K3.1 Pro models run at max effort only, `kimi/kimi-k2.6` switches thinking
    with `enable_thinking`, and the K2.7 Code models take no thinking
    parameter.
- The terminal UI now shows a model's effort when it has only one, such as
  "max effort" in the welcome banner and the `/model` picker. Previously it
  showed only "thinking mode".

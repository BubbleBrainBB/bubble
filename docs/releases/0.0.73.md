# Bubble 0.0.73

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Fixed

- The welcome screen no longer shows an effort grade for a model that has
  none. With Nex-N2.6 on MOSS it read `Nex-N2.6 with medium effort · moss`;
  it now reads `Nex-N2.6 · thinking mode · moss`. "medium" was the value
  Bubble stores for "thinking is on" and was never sent to the provider. The
  same wrong line appeared for Kimi K2.7 Code and Kimi for Coding, which
  always think, and for Kimi K2.5 and K2.6, which only switch thinking on and
  off.
- GLM-4.6, GLM-4.7, GLM-5.1 and GLM-5-Turbo on the Zhipu and Z.AI providers
  only switch thinking on and off, and are now shown that way: the welcome
  screen reads `GLM-5.1 · thinking mode · zhipuai`, and the second step of
  `/model` offers "on" and "off" in place of "medium" and "off". GLM-5.2 and
  the GLM-5.3 family take real grades and are unchanged.
- The Session info tab of `/context` showed the stored value as
  `Reasoning effort` for every model. For a model that always thinks it now
  reads `Thinking: always on`, for an on/off model `Thinking: on` or `off`.
  A model with real grades still shows its grade.

Requests sent to providers are the same as in 0.0.72. Only what the terminal
shows has changed.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

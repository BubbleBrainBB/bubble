# Bubble 0.0.64

This release puts the TypeScript Bubble back in the `@bubblebrain-ai/bubble`
npm package. 0.0.63 replaced it with the native (Rust) build, which is still
missing parts of the TypeScript version: the Agent SDK, the Feishu bot,
background tasks, the `question` tool, LSP, `/goal`, `/rewind` and permission
rules. The code in 0.0.64 is the same as 0.0.62. It does not publish a
desktop application update.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

From 0.0.63, `bubble update` installs it too.

## Coming from 0.0.63

- `~/.bubble/config.json`, `auth.json`, `settings.json`, skills and agent
  profiles are shared by both versions and work as they are.
- Sessions from before 0.0.63 are still in `~/.bubble/sessions`; `/session`
  and `-r` continue them.
- Sessions started in 0.0.63 are stored in `~/.bubble/native/bubble.db`, which
  this version does not read. The file is left in place.
- Sign-ins to MCP servers made with `/mcp login` (`~/.bubble/mcp-auth.json`)
  are not used by this version.

## Restored

- The Agent SDK (`import … from "@bubblebrain-ai/bubble"`).
- The Feishu bot (`bubble serve --feishu`).

# Bubble 0.0.69

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Fixed

- A model that works in silence for more than five minutes is no longer cut
  off. Node's fetch gives up on a response after 300 seconds without a byte.
  0.0.68 took the OpenAI-compatible providers off that limit; Gemini,
  Anthropic, Volcengine Ark, OpenCode Zen, ChatGPT and Grok were still on it.
  Gemini over the Gemini API sends a tool call whole, so a turn that wrote a
  large file failed with `Gemini stream interrupted: Failed to process
  successful response` and was retried ten times into the same limit. Every
  provider now waits as long as `BUBBLE_PROVIDER_REQUEST_TIMEOUT_MS` says, and
  without limit when it is not set, whether the connection is direct, through
  a proxy or uses a custom CA.
- A reply cut by a request timeout you did set is retried once instead of up
  to ten times, and Gemini says what happened: `the model sent nothing for
  300s, the limit set by BUBBLE_PROVIDER_REQUEST_TIMEOUT_MS`.
- Requests that run unseen have limits of their own, now that the connection
  no longer ends them: a session title or a memory pass is limited to 300
  seconds (or the request timeout you set), Gemini model discovery to 15
  seconds, and the token exchange at the end of a ChatGPT or Grok sign-in to
  30 seconds. In 0.0.68 a title or memory request to an OpenAI-compatible
  provider could wait forever on a connection that stayed open and sent
  nothing.
- GLM models show a file while it is being written. Zhipu and Z.AI send a tool
  call whole unless asked to stream it, so the `Write` row appeared only when
  the file was finished, up to a minute in. Requests now ask for it
  (`tool_stream`), and the row appears within the first seconds. Gemini over
  the Gemini API has no such option: the turn no longer fails, but the screen
  shows only the spinner while it writes.
- The token count beside the spinner includes a file being written. It added
  up reply text and reasoning only, so it stood still for as long as a write
  took.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.

# Bubble 0.0.70

This release updates the `@bubblebrain-ai/bubble` npm package, including the
Agent SDK and terminal CLI. It does not publish a desktop application update.

## Added

- Gemini 4 Neon (`gemini-4-neon`) on the Google Gemini provider. Google places
  it between Gemini 4 Carbon and Gemini 4 Hydrogen. It shares their
  1,048,576-token window, thinks at low, medium, high (default) or xhigh, and
  is on the paid tier of the Gemini API only. Argon stays first in the list, so
  the default model does not change.
- Gemini 4 Neon is priced at $3 input, $15 output and $0.15 cached input per
  million tokens, at one rate for all context lengths.
- Live Gemini model discovery recognizes the `neon` tier. The five listed
  models are now Argon, Carbon, Neon, Hydrogen and Gemini 3.8 Flash; Gemini 3.7
  Flash, which Google routes to 3.8 Flash, no longer makes the list. A list
  saved by an earlier version is not reused, so `/model` shows Neon right after
  the upgrade.

## Changed

- Gemini 3.5 Flash is no longer a built-in model. Google has deprecated it and
  routes it to Gemini 3.6 Flash.
- A Gemini model id without a version number, such as `gemini-flash-latest`,
  is never listed by Bubble and is given no thinking levels. Written into
  `models.json` it is still your model, run at the level you ask for.
- xhigh is sent only to the Gemini 4 models verified to take it: Hydrogen and
  Neon. On Argon and Carbon, which answer it with HTTP 400, xhigh and max are
  still sent as high.
- Agent SDK and `bubble host`: a turn runs at a thinking level the model has,
  and `turn/started` reports that level. A level you pass, or the default in
  `config.json`, is fitted to the model's own levels the way the CLI has always
  done it. Before, the SDK passed the level on unchanged and reported it
  unchanged, so a Gemini 4 turn asked to think at `off` said `off` while the
  request went out at `low`. If you call the SDK or the host yourself, three
  things differ from 0.0.69:
  - A level the model does not have becomes the nearest one below it, or its
    lowest. ChatGPT, OpenRouter and OpenCode Zen's Space Bunny used to replace
    such a level with the model's default.
  - A Gemini 3 Flash that cannot turn thinking off is sent `minimal` where it
    was sent a thinking budget of 0.
  - A level that is not a level (JSON `null`, an unknown word) counts as not
    given, and the model's default applies. This holds for
    `defaultThinkingLevel` in `config.json` too.

  A model Bubble knows nothing about keeps the level you asked for.

## Fixed

- A model you list in `models.json` under the id of a built-in model keeps
  that model's thinking levels, default level and context window. Listing
  Gemini 4 Hydrogen, for example, used to drop its default from high to medium
  and lose its context window.
- A model list in `models.json` takes effect at once. When the provider's own
  list had already been saved, Bubble kept using the saved one at startup and
  for up to a day afterwards.
- A Gemini model listed in `models.json` that Bubble does not ship keeps its
  thinking levels. They were there the first time the list was read and gone
  the second.
- A model list saved for another API key, another account or another endpoint
  no longer decides what a provider's models can do when Bubble starts.

## Install

```bash
npm install -g @bubblebrain-ai/bubble
```

`bubble update` installs it too.
